# go-pass

パスワード用のランダムな文字列を生成する、Go製のコマンドラインツールです。

```console
$ go-pass
}<}=tvN7F_C#
```

- 既定では、大文字・小文字・数字・記号をすべて含む12桁のパスワードを1つ出力します。
- 使う文字種は、それぞれ最低1文字ずつ必ず含まれます。
- 乱数には `crypto/rand` を使っています。
- 生成したパスワードは標準出力に表示するだけで、ファイルやログには保存しません。

## インストール

Go 1.27 以降が必要です。

```bash
go install github.com/masakiwakabayashi/go-pass@latest
```

ソースコードからインストールする場合は、リポジトリのフォルダで次を実行します。

```bash
go install
```

インストール先は `$(go env GOPATH)/bin`（通常は `~/go/bin`）です。`go-pass` が見つからない場合は、このフォルダをPATHに追加してください（zshの例）。

```bash
echo 'export PATH="$HOME/go/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

## 使い方

```bash
go-pass [オプション]
```

### オプション

| オプション | 内容 | 既定値 |
| --- | --- | --- |
| `-l <数>` | パスワードの桁数（最大25） | 12 |
| `-ns` | 記号を使わない | オフ |
| `-nu` | 大文字を使わない | オフ |
| `-h` | 使い方を表示する | |

オプションは `-ns -nu` のように別々に書きます（`-nsnu` のようにまとめては書けません）。

### 例

```console
$ go-pass -l 20
=bl7(QLPI+cJtrqCxg_!

$ go-pass -ns
0cwtnOmrmMHf

$ go-pass -nu
g{4=s$--*g%k

$ go-pass -ns -nu -l 16
z69raf65nxtjwehm
```

macOSでは、画面に表示せずにクリップボードへコピーできます。

```bash
go-pass | pbcopy
```

## 使われる文字

| 文字種 | 文字 | オフにするオプション |
| --- | --- | --- |
| 大文字 | `A`〜`Z` | `-nu` |
| 小文字 | `a`〜`z` | なし |
| 数字 | `0`〜`9` | なし |
| 記号 | `` !@#$%^&*()-_=+[]{}<>? `` | `-ns` |

## 桁数の範囲

使う文字種はそれぞれ最低1文字含めるため、最小の桁数は使う文字種の数と同じです。

| 設定 | 使う文字種 | 指定できる桁数 |
| --- | --- | --- |
| 既定 | 大文字・小文字・数字・記号 | 4〜25 |
| `-ns` | 大文字・小文字・数字 | 3〜25 |
| `-nu` | 小文字・数字・記号 | 3〜25 |
| `-ns -nu` | 小文字・数字 | 2〜25 |

範囲外の桁数を指定すると、エラーになります。

```console
$ go-pass -l 3
エラー: 桁数（3）は有効な文字種の数（4）以上にしてください
```

## 終了コード

| コード | 意味 |
| --- | --- |
| 0 | 成功（`-h` で使い方を表示した場合を含む） |
| 1 | エラー（桁数が範囲外、不正なオプション、余分な引数など） |

エラーメッセージは標準エラー出力に表示されます。

## 開発

```bash
go run .          # 実行

go vet ./...      # 静的チェック
gofmt -l .        # 整形が必要なファイルの確認
```
